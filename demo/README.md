# 60–90 Second Demonstration Video Plan

Record the video only after the corresponding actions work in Ubuntu.

## Suggested sequence

1. 0–10 seconds: show Ubuntu and identify ROS 2 Jazzy, Gazebo Harmonic, and TurtleBot3 Burger.
2. 10–20 seconds: show Gazebo and the TurtleBot3 in the empty world.
3. 20–35 seconds: run the automatic controller and show forward, stop, backward, stop, left, stop, right, and final stop.
4. 35–55 seconds: run the keyboard controller and demonstrate W, S, A, D, and Space.
5. 55–65 seconds: press P and show X, Y, heading, and velocity output.
6. 65–75 seconds: show `/cmd_vel` and `/odom` topic information.
7. 75–90 seconds: press Q and summarize the project.

Use 720p or 1080p recording and save the result as `demo/robot_motion_demo.mp4`.
